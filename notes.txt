headroom.
pagecache holds graph store in RAM, we couldn't set it to 10 because it was to big but 3GB is enough for this project

1.2
=============
capture.py imports the generator as g, prints g.dataset_info() and g.FIELDS, and previews ten records from 
each iter_<stream>() using itertools.islice on fresh iterators. It then writes each stream to CSV 
with csv.DictWriter (header first, one row at a time), so no stream is held in memory, and logs progress every 
million transfers.
